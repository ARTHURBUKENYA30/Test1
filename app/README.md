# UPPC Digital Museum — Final

A production-oriented digital museum and heritage archive platform for Uganda Printing and Publishing Corporation (UPPC).

## Included

- Public digital museum experience
- Museum collections and machine catalogue
- Digital archive structure
- Historical timeline
- Exhibitions
- Education/research sections
- Virtual museum foundation
- Visitor enquiry workflow
- Authenticated staff admin portal
- PostgreSQL/Supabase schema
- Row Level Security policies
- Public/private storage buckets
- Curatorial Draft → Publish workflow
- Public image and private archive upload paths
- JSON export
- Supplied museum photographs and UPPC logo

## Start

```bash
npm install
npm run dev
```

See `UPPC-MUSEUM-FINAL-SETUP.md` for the complete deployment and Supabase setup.

## Important

Prototype historical text must be reviewed and approved by UPPC museum/curatorial staff before publication.
